Créer le prototype frontend complet d’une plateforme web professionnelle, moderne et intelligente de gestion de flotte téléphonique, destinée à une entreprise. Nom du projet : “Plateforme intelligente de gestion de flotte téléphonique basée sur l’analytics prédictif et la détection d’anomalies” Objectif du site : Le site web doit permettre de centraliser et visualiser les données d’une flotte téléphonique d’entreprise, suivre les coûts, détecter les anomalies de consommation, afficher des prédictions de coûts futurs, générer des alertes, proposer des recommandations d’optimisation, et aider à la prise de décision. Style global souhaité : - Design SaaS professionnel, moderne, propre, premium - Inspiré de Vercel, Linear, Stripe Dashboard, Power BI moderne - Interface en français - Fond clair élégant avec sections blanches, gris très clair et touches bleu / cyan / violet léger - Apparence très professionnelle pour soutenance de PFE - Typographie moderne type Inter / Manrope - Icônes simples, modernes, cohérentes - Cartes avec coins arrondis - Ombres légères - Beaucoup d’espace entre les éléments - Dashboard responsive desktop-first - Style analytique et data-driven - Interface réaliste et prête à être codée ensuite en React, Angular ou HTML/CSS Structure attendue : Créer plusieurs écrans / pages reliés entre eux dans un même prototype web desktop. Pages à générer : 1. Page de connexion 2. Tableau de bord principal 3. Page gestion des lignes 4. Page gestion des forfaits 5. Page consommation / historique 6. Page anomalies & alertes 7. Page prédictions & analytics 8. Page recommandations d’optimisation 9. Page rapports & exports 10. Page utilisateurs / rôles 11. Page paramètres 12. Détail d’une ligne téléphonique 13. Détail d’une alerte 14.
